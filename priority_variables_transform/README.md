# Priority Variables Transform

This directory contains the **active ingest transformation YAML files** used
in the NHLBI BioData Catalyst harmonization pipeline. Each `<STUDY>-ingest/`
subdirectory holds the current LinkML-Map transformation specs for that cohort.

## Active Directories

| Directory | Description |
|---|---|
| `ARIC-ingest/` | ARIC ingest transformations |
| `CARDIA-ingest/` | CARDIA ingest transformations |
| `CHS-ingest/` | CHS ingest transformations |
| `COPDGene-ingest/` | COPDGene ingest transformations |
| `FHS-ingest/` | FHS ingest transformations |
| `HCHS-ingest/` | HCHS/SOL ingest transformations |
| `JHS-ingest/` | JHS ingest transformations |
| `MESA-ingest/` | MESA ingest transformations |
| `WHI-ingest/` | WHI ingest transformations |

## Archived (`_archive/`)

Legacy directories from earlier phases of the harmonization work have been
moved to [`_archive/`](_archive/). These include the original per-study
transformation directories, batch-conversion scripts, and experimental work.

- @sigfried copied the remaining, unconverted files into
  [input_directory](_archive/batch_converting/input_directory), and used
  [linkml_transform_script.py](_archive/batch_converting/linkml_transform_script.py)
